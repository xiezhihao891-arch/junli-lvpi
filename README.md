# 军理绿皮新版（junli-lvpi）

中大军事理论考前复习站 · 对齐新教材重点笔记（绿皮）。

## 页面

- `index.html` — 枢纽
- `quiz.html` — 刷题（单选/多选/判断/填空）
- `memo.html` — 背诵（闪卡/挖空/时间轴）
- `diff.html` — 与旧资料/易错点差异

## 声明

基于詹哲轩「中大军理新教材重点内容」笔记与 2019 大纲公开结构；对应教材 ISBN 978-7-306-07893-3。**非出版社全书复制**，以课堂为准。

## 本地

静态站点，直接打开或 `python -m http.server`。含 `.nojekyll`，适合 GitHub Pages。
